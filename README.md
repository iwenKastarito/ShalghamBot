# Shalgham Chess Engine

Shalgham is a powerful chess engine written in C++ with SFML graphics. It features a graphical user interface, Lichess API integration for online play, and comprehensive test coverage.

## Features

- Interactive graphical chess board using SFML
- Strong chess AI engine
- Lichess API integration for online play
- Comprehensive test suite
- Support for standard chess rules including:
  - Castling
  - En passant
  - Pawn promotion
  - Check/checkmate detection
  - Draw detection (stalemate, 50-move rule)
